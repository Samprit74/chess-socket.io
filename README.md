# ♟️ Chess Socket.IO

![Chess Banner](https://img.freepik.com/premium-vector/check-checkmate-landing-page-design-template-online-chess-club-personal-training-class_341509-5995.jpg)

> Play real-time multiplayer chess online using **Node.js**, **Express**, and **Socket.IO**!  

---

## 🚀 Features

- 🎮 Real-time multiplayer chess  
- 🔄 Synchronized board between players  
- 🖱️ Click or drag pieces to move  
- 🏆 Spectator mode for others to watch  
- 👑 Highlights legal moves on hover  
- 🔄 Pawn promotion popup  

---

## 🛠️ Tech Stack

- **Node.js** - Backend runtime  
- **Express** - Server framework  
- **Socket.IO** - Real-time communication  
- **Chess.js** - Game logic  
- **EJS** - Templating engine  
- **Tailwind CSS** - Styling  

---

## 📦 Installation

Clone the repo:

```bash
git clone https://github.com/Samprit74/chess-socket.io.git
cd chess-socket.io
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node server.js
```

Open your browser and go to:  

```
http://localhost:8000
```

---

## 🎯 How to Play

1. The first two connected players will be assigned **White** and **Black**.  
2. Additional users will join as **spectators**.  
3. Click or drag pieces to make moves.  
4. Legal moves are highlighted when you hover over a piece.  
5. Pawn promotion popup will appear automatically when needed.
