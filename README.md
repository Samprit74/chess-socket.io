## 🚀 Features

- 🎮 Real-time multiplayer chess
- 🔄 Synchronized board between players
- 🖱️ Click or drag pieces to move
- 🏆 Spectator mode for others to watch
- 👑 Highlights legal moves on hover
- 🔄 Pawn promotion popup
- 🟦 Flipped board for black player
- ⚡ Check detection with visual highlight

---

## 🛠️ Tech Stack

- **Node.js** - Backend runtime  
- **Express** - Server framework  
- **Socket.IO** - Real-time communication  
- **Chess.js** - Game logic  
- **EJS** - Templating engine  
- **Tailwind CSS** - Styling  

---

## 📦 Installation

Clone the repo:
```bash
git clone https://github.com/Samprit74/chess-socket.io.git
cd chess-socket.io
```

Install dependencies:
```bash
npm install
```

Run the server:
```bash
node server.js
```

Open your browser at:
```
http://localhost:8000
```

---

## 🎮 How to Play

1. Open the game in two different browsers or devices.
2. One player will be assigned **White**, the other **Black**.
3. Click or drag a piece to see its legal moves.
4. Spectators can watch the game in real-time.
5. Check and pawn promotion are handled automatically.
